🛠 工具调用 Function Calling

留空则使用内置 3 个工具：天气 / 时间 / 加密货币 / 读文件 / 维基百科 / 快递 / 一言 / 算数 / 萌宠图 / 定位 / 拍照 / 通知 / 剪贴板 / 朗读 / 我的世界百科。工具调用会真实执行并把结果回传给模型。

🖼 图片输入 多模态

启用后输入框左侧出现 📎 按钮，可发送图片给模型（需模型支持视觉）。图片以 base64 内联，不会上传到第三方。

开启后每条回复会用系统语音朗读（自动过滤【】和动作描述）。默认关闭，适合安静场合。

默认关闭：幽灵模式只在离线知识库中自问自答，不会产生任何费用。勾选后才会真的请求 API（最多 20 条）。

🔌 自定义协议 请求格式

勾选后会强制发送 enable_thinking:false，能有效避免 Qwen 等模型过度思考。
